
# LMS Administration - Operational Guide

## 1. Purpose

LMS administration ensures that employees receive the right learning content, at the right time, with accurate tracking and reporting.

## 2. LMS Administration Lifecycle

1. Identify training requirements.
2. Create or update courses.
3. Upload learning content.
4. Configure course settings.
5. Assign learners.
6. Set due dates.
7. Monitor progress.
8. Generate reports.
9. Resolve learner issues.
10. Review course effectiveness.

## 3. User Administration

Important activities:

- User account creation
- Employee data validation
- User group allocation
- Role assignment
- Account deactivation
- Access management

## 4. Course Administration

Important activities:

- Course creation
- Course categorisation
- Learning path configuration
- Assessment setup
- Completion criteria
- Course version control
- Content review

## 5. Training Compliance

Track:
- Mandatory training
- Overdue assignments
- Expired certifications
- Assessment failures
- Incomplete learning
- Compliance exceptions

## 6. LMS Troubleshooting

| Issue | Possible Investigation |
|---|---|
| Course not visible | Check assignment and access |
| Completion not updated | Check completion criteria and tracking |
| Login failure | Check account and authentication |
| Assessment error | Check configuration and attempt rules |
| Certificate missing | Check eligibility and completion status |
| Incorrect report | Check filters and source data |

## 7. LMS Quality Checklist

- Correct learner population
- Correct course assignment
- Accurate due dates
- Correct completion settings
- Valid learning content
- Accurate reporting
- Appropriate user permissions
- Documented issue resolution

## 8. Key Performance Indicators

- Assignment completion rate
- On-time completion rate
- Assessment pass rate
- Learner engagement
- Training overdue rate
- Training hours delivered

## 9. Governance Principles

- Maintain accurate records.
- Restrict access based on roles.
- Review course content regularly.
- Maintain version history.
- Protect employee information.
- Validate reports before distribution.
- Follow organisational retention policies.
