
# Training and Learning Management Systems (LMS)

## 1. Introduction

Learning and Development (L&D) helps organisations improve employee knowledge, skills, productivity and performance.

A Learning Management System (LMS) is a digital platform used to create, distribute, manage and track employee learning programmes.

## 2. Popular LMS Platforms

| LMS Platform | Key Application |
|---|---|
| Litmos | Corporate learning and compliance |
| Docebo | Enterprise learning management |
| Cornerstone | Talent and learning management |
| Moodle | Open-source learning |
| TalentLMS | Corporate training |
| Absorb LMS | Enterprise learning |

### Course Management

## 5. Training Delivery Models

### Instructor-Led Training (ILT)
Traditional classroom-based training.

### Virtual Instructor-Led Training (VILT)
Online instructor-led sessions.

### E-Learning
Self-paced digital learning.

### Blended Learning
Combination of instructor-led and digital learning.

## 6. ADDIE Instructional Design Model

| Stage | Description |
|---|---|
| Analysis | Identify learning requirements |
| Design | Define learning objectives |
| Development | Develop training content |
| Implementation | Deliver training |
| Evaluation | Measure effectiveness |
