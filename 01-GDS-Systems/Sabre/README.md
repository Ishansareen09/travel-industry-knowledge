
# Sabre GDS - Complete Learning Guide

## 1. Introduction

Sabre is a Global Distribution System (GDS) that connects travel agencies, airlines and other travel suppliers.

It supports flight shopping, reservations, ticketing and post-booking servicing.

## 2. Core Functionalities

- Flight availability
- Passenger Name Record (PNR)
- Fare pricing and quotation
- Ticket issuance
- Ticket exchanges and reissues
- Refund processing
- Queue management
- Ancillary services

## 3. Passenger Name Record (PNR)

A PNR is a booking record containing passenger and itinerary information.

### Common PNR Elements

| Element | Description |
|---|---|
| Passenger Name | Traveller's name |
| Itinerary | Flight segments |
| Contact | Passenger contact information |
| SSR | Special Service Request |
| OSI | Other Service Information |
| Ticketing | Ticketing arrangements |
| Received From | Source of booking instructions |

## 4. Ticketing Process

1. Search flight availability.
2. Select suitable flights.
3. Create passenger booking.
4. Enter required passenger information.
5. Price the itinerary.
6. Review fare rules.
7. Complete authorised payment.
8. Issue the ticket.
9. Verify ticket status.

## 5. Ticket Servicing

### Reissue / Exchange

A ticket may need to be exchanged when a passenger changes travel dates, flights or other permitted itinerary details.

Check:
- Original fare rules
- Change penalty
- Fare difference
- Tax difference
- Ticket validity
- Airline authorisation

### Refund

Before processing a refund, verify:
- Ticket coupon status
- Fare refundability
- Cancellation penalty
- No-show conditions
- Applicable taxes
- Airline refund conditions

## 6. Queue Management

Queues help travel agents organise booking records requiring attention.

Examples include:
- Schedule changes
- Ticketing deadlines
- Customer follow-ups
- Airline confirmations
- Servicing requests

## 7. Quality Checklist

- Correct passenger details
- Correct flight itinerary
- Correct booking class
- Fare rules reviewed
- Ticket status verified
- Booking confirmation checked
