
# Amadeus GDS - Complete Learning Guide

## 1. Introduction

Amadeus is a global travel technology provider offering reservation, distribution and airline retailing solutions.

It is widely used by travel agencies, airlines and travel management companies.

## 2. Core Functionalities

- Flight availability
- Passenger Name Record (PNR)
- Fare pricing
- Ticket issuance
- Ticket reissues
- Refund processing
- Ancillary services
- Queue management

## 3. PNR Management

A Passenger Name Record contains information related to a passenger's booking.

### Key PNR Components

| Component | Description |
|---|---|
| Passenger Name | Traveller details |
| Itinerary | Flight segments |
| Contact Details | Email and telephone |
| SSR | Special Service Request |
| OSI | Other Service Information |
| Ticketing | Ticketing arrangements |
| Remarks | Booking-related information |

## 4. Flight Booking Workflow

1. Search flight availability.
2. Select suitable flights.
3. Create the booking record.
4. Add passenger details.
5. Add mandatory contact information.
6. Price the itinerary.
7. Review fare rules.
8. Complete payment.
9. Issue the ticket.
10. Verify ticket status.

## 5. Fare Management

Important fare conditions include:

- Fare basis
- Booking class
- Advance purchase
- Minimum stay
- Maximum stay
- Change penalties
- Cancellation penalties
- Baggage allowance
- No-show conditions

## 6. Ticket Reissue and Exchange

A ticket exchange may be required when a passenger changes an existing itinerary.

### Important Checks

- Original ticket validity
- Fare difference
- Change penalty
- Tax difference
- Coupon status
- Airline restrictions
- Waiver requirements

## 7. Refund Management

Before processing a refund:

1. Verify ticket status.
2. Check used and unused coupons.
3. Review fare refund rules.
4. Check cancellation penalties.
5. Verify refundable taxes.
6. Review ancillary services.
7. Follow airline refund procedures.

## 8. Queue Management

Queues help manage operational tasks such as:

- Schedule changes
- Ticketing deadlines
- Booking follow-ups
- Airline confirmations
- Customer requests

## 9. Quality Checklist

- Passenger name verified
- Correct flight segments
- Booking class verified
- Fare conditions explained
- Ticket issued successfully
- Ticket number and status verified
- Customer confirmation shared securely

## 10. Learning Objectives

- Understand Amadeus reservation workflows.
- Learn PNR management.
- Understand ticket issuance.
- Develop fare-rule knowledge.
- Understand exchanges and refunds.
