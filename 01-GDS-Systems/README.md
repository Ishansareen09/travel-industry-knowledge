
# GDS Systems

Global Distribution Systems (GDS) connect travel suppliers and travel sellers to support flight shopping, reservations, ticketing and servicing.

## Platforms

### 1. Sabre
- Flight availability
- PNR management
- Fare pricing
- Ticketing
- Refunds and exchanges
- Queue management

### 2. Amadeus
- Flight reservations
- PNR management
- Fare quotation
- Electronic ticketing
- Reissues and refunds

### 3. Travelport / Galileo
- Flight availability
- Booking management
- Fare management
- Ticket servicing
- Queue processing

## Important Industry Terms

| Term | Meaning |
|---|---|
| GDS | Global Distribution System |
| PNR | Passenger Name Record |
| SSR | Special Service Request |
| OSI | Other Service Information |
| EMD | Electronic Miscellaneous Document |
| E-ticket | Electronic Ticket |
| PCC | Pseudo City Code |

## Learning Objectives

- Understand GDS architecture.
- Understand booking lifecycle.
- Learn PNR structure.
- Understand ticket issuance.
- Learn post-booking servicing.
