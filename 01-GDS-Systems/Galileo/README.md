
# Travelport Galileo - Complete Learning Guide

## 1. Introduction

Travelport Galileo is a travel distribution platform used by travel agencies and travel management companies to search, book and manage travel services.

## 2. Core Functionalities

- Flight availability
- Passenger booking management
- PNR creation and servicing
- Fare pricing and quotation
- Ticket issuance
- Ticket exchanges
- Refund processing
- Queue management

## 3. Booking File / PNR

A booking record contains important information about a passenger's travel arrangements.

### Key Components

| Component | Description |
|---|---|
| Passenger Name | Traveller information |
| Flight Segments | Selected itinerary |
| Contact Information | Passenger contact |
| SSR | Special Service Request |
| OSI | Other Service Information |
| Ticket Information | Electronic ticket details |
| Remarks | Booking-related notes |

## 4. Flight Booking Workflow

1. Understand passenger requirements.
2. Search flight availability.
3. Select suitable flights.
4. Create the booking record.
5. Enter passenger information.
6. Price the itinerary.
7. Review fare conditions.
8. Complete authorised payment.
9. Issue the ticket.
10. Verify booking and ticket status.

## 5. Fare Management

Important fare components:

- Fare basis
- Booking class
- Fare family
- Advance purchase
- Minimum stay
- Maximum stay
- Change conditions
- Refund conditions
- Baggage allowance

## 6. Ticket Servicing

### Ticket Exchange

Review:
- Original ticket conditions
- Change penalty
- Fare difference
- Tax difference
- Ticket validity
- Airline restrictions

### Refund Processing

Review:
- Ticket coupon status
- Refundability
- Applicable penalties
- No-show restrictions
- Refundable taxes
- Airline policy

## 7. Queue Management

Queue management helps organise records requiring action.

Common operational cases:
- Schedule changes
- Ticketing deadlines
- Airline confirmations
- Customer follow-ups
- Booking errors

## 8. Operational Quality Checklist

- Correct passenger details
- Correct itinerary
- Correct booking class
- Fare conditions verified
- Ticket status checked
- Confirmation sent securely

## 9. Learning Objectives

- Understand Travelport Galileo workflows.
- Learn booking management.
- Understand airline ticketing.
- Develop fare-rule knowledge.
- Understand refund and exchange processes.
