
# Travel Technology Knowledge Centre

## 1. Introduction

Travel technology enables airlines, travel agencies, OTAs and travel management companies to connect, distribute and manage travel services.

## 2. Major Technology Areas

- Global Distribution Systems (GDS)
- New Distribution Capability (NDC)
- Application Programming Interfaces (APIs)
- Online Travel Agency platforms
- Airline Reservation Systems
- Payment Gateways
- Revenue Management Systems
- Customer Relationship Management (CRM)

## 3. New Distribution Capability (NDC)

NDC is an IATA-developed standard that supports airline retailing and richer travel offers through modern data exchange.

Key concepts:
- Offer creation
- Order management
- Ancillary services
- Branded fares
- Airline distribution
- Post-booking servicing

Read: NDC-Overview.md

## 4. API in Travel Industry

An API allows different software applications to exchange information.

Common travel API applications:
- Flight search
- Fare pricing
- Availability
- Hotel booking
- Booking confirmation
- Ticket management
- Seat selection
- Baggage information

## 5. Online Travel Agencies (OTAs)

OTAs allow travellers to search, compare and book travel products online.

Examples:
- MakeMyTrip
- Goibibo
- Expedia
- Booking.com
- Trip.com
- Cleartrip

## 6. OTA Business Workflow

1. Customer searches for a flight.
2. OTA requests available inventory.
3. Supplier returns flight options.
4. OTA displays fares.
5. Customer selects an option.
6. Booking and payment are processed.
7. Supplier confirms the booking.
8. Ticket or travel document is issued.
9. OTA provides post-booking support.

## 7. Travel Technology Ecosystem

Airlines → GDS / NDC Providers → Travel Agencies / OTAs → Customers

Payment providers, aggregators and other technology partners may also participate.
