
# Travel Industry Glossary

A reference guide to commonly used terminology across the airline, travel, GDS, ticketing and travel technology industries.

## 1. GDS and Reservation Terminology

| Term | Full Form / Meaning |
|---|---|
| GDS | Global Distribution System |
| PNR | Passenger Name Record |
| CRS | Computer Reservation System |
| PCC | Pseudo City Code |
| SSR | Special Service Request |
| OSI | Other Service Information |
| OID | Office ID |
| E-ticket | Electronic Ticket |
| EMD | Electronic Miscellaneous Document |
| Segment | A flight or travel sector within an itinerary |

## 2. Airline Ticketing and Fare Terminology

| Term | Meaning |
|---|---|
| ATPCO | Airline Tariff Publishing Company |
| Fare Basis | Code identifying a specific fare product |
| Fare Rules | Conditions governing a ticket or fare |
| Base Fare | Main fare amount before applicable taxes and fees |
| Taxes | Government and other applicable charges |
| YQ / YR | Airline-imposed surcharges, where applicable |
| Reissue | Changing an issued ticket by exchanging it for another ticket |
| Refund | Returning eligible ticket value according to applicable rules |
| No-show | Passenger does not travel or comply with applicable check-in requirements |
| Penalty | Charge that may apply to a change or cancellation |
| Fare Difference | Difference between the original and new fare |
| Ticket Validity | Period during which a ticket may be used, subject to its conditions |

## 3. Airport and Airline Operations

| Term | Meaning |
|---|---|
| PNR | Passenger Name Record |
| DCS | Departure Control System |
| Check-in | Passenger acceptance process before departure |
| Boarding Pass | Document or digital credential used for boarding |
| Gate | Airport location where passengers board an aircraft |
| Baggage Allowance | Permitted baggage under applicable ticket conditions |
| Transit | Passenger continues through an intermediate airport |
| Layover | Time spent between connecting flights |
| Turnaround Time | Time between aircraft arrival and its next departure |
| Load Factor | Percentage of available passenger capacity occupied |

## 7. Important Industry Notes

- GDS commands and workflows differ across Sabre, Amadeus and Galileo.
- Fare rules and refund eligibility must be checked against the actual ticket and applicable airline conditions.
- NDC is an airline distribution standard; implementation varies between airlines and technology providers.
- Operational KPIs should be interpreted using the organisation's agreed definitions.

## Disclaimer

This glossary is an educational reference. Terminology, airline procedures and technical standards may vary by airline, market, GDS and service provider. Always consult current official documentation for operational decisions.
