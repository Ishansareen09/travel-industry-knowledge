
# ATPCO - Airline Fare Filing and Pricing Knowledge Centre

## 1. Introduction

ATPCO (Airline Tariff Publishing Company) provides airline pricing and fare-related data services that support the global airline distribution ecosystem.

It plays an important role in airline fare distribution, pricing and retailing.

## 2. What is Fare Filing?

Fare filing is the process of creating and distributing airline fare information with applicable conditions and restrictions.

A fare record may include:

- Origin and destination
- Airline carrier
- Fare amount
- Currency
- Booking code applicability
- Fare basis
- Effective dates
- Fare rules
- Routing restrictions
- Passenger eligibility

## 3. Important Fare Components

| Component | Description |
|---|---|
| Fare Basis | Airline-defined fare identifier |
| Booking Code | Reservation inventory class |
| Rule | Conditions associated with a fare |
| Routing | Permitted travel routing |
| Currency | Currency of the filed fare |
| Effective Date | Date from which a fare applies |
| Discontinue Date | Date after which a fare is no longer applicable |
| Passenger Type | Applicable passenger category |
| Tax | Applicable government and airport charges |

## 5. Fare Filing Quality Checks

Before a fare is distributed, review:

- Correct airline carrier
- Correct origin and destination
- Correct currency and amount
- Booking code applicability
- Fare basis consistency
- Effective and discontinue dates
- Rule application
- Routing restrictions
- Passenger eligibility
- Data validation
